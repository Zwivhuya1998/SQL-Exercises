# SQL Exercises and Practice

Welcome to my SQL practice repository!

This repository documents my learning journey in **Business Analytics**, with a focus on developing practical SQL skills for querying databases, analysing data, and extracting meaningful insights.

## 📚 What You'll Find Here

The exercises in this repository cover fundamental SQL concepts, including:

- **Basic SQL Queries:** Retrieving data from database tables.
- **Filtering Data:** Using `WHERE` conditions to select relevant records.
- **Sorting and Grouping:** Organising data using `ORDER BY` and `GROUP BY`.
- **Aggregate Functions:** Applying functions such as `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
- **SQL Operators and Conditions:** Using operators to analyse and filter information.
- **NULL Values:** Understanding and handling missing data.
- **Data Analysis:** Using SQL queries to answer business-related questions.
