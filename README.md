# SQL Exercise
This repository contains my SQL exercises and practice activities completed as part of my Business Analytics learning journey.
The exercises focus on using SQL to work with databases, including:

* Writing basic SQL queries
* Selecting and filtering data
* Sorting and grouping data
* Using functions and conditions
* Working with NULL values
* Extracting useful information from datasets

The purpose of this exercise is to develop practical SQL skills and improve my ability to use data to answer business-related questions.
